# 常用物体与视口放置

编辑器的“常用物体”是独立停靠窗口，默认位于左栏上方。支持搜索立方体、平面、方向光、点光源、聚光灯、矩形光和圆盘光；这些模板来自 [`Content/Objects/basic.textproto`](../Content/Objects/basic.textproto)，使用与场景相同的 Protobuf 协议。模板不会作为可见物体提前加入用户场景。

## 操作

1. 按住物体行并拖入视口图像，绿色接触标记与线框显示当前预览。
2. 松开左键创建一次实例，并在详情窗口显示选中物体的数值。
3. `Ctrl+Z` 撤销整次创建，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。详情的恢复对象默认值会恢复到创建时的放置结果。

拖出图像后释放、按 `Escape` 或应用失焦会取消本次放置。拖动期间视口选择、Gizmo 和相机导航不处理同一次输入。Play 模式仍沿用当前编辑器的实体创建规则。

## 落点

射线使用图像的实际显示矩形、活动相机及近远裁剪范围。最近交点沿用普通选择的单面、双面和 alpha MASK 接受规则。没有可见交点时，先尝试世界 `Y=0` 平面；无法命中地面时，使用相机正前方三米处的平面。落点超出裁剪范围则不创建。

立方体为一米边长，原点位于底面中心；平面为一米 XZ 平面，法线朝正 Y。几何保持配置朝向，通过变换后的包围盒支撑贴在接触面外；不会自动旋转去贴合墙面。平面额外保留一毫米间距，避免共面闪烁；灯光沿接触法线偏移 0.15 米。启用工具栏吸附或拖动时按住 `Ctrl`，按移动步长吸附接触位置，并投影回接触平面以避免舍入造成穿墙。这不是顶点吸附或碰撞求解。

`EditorUi` 持有一份拾取缓存，供点击选择、材质投放和物体放置共同使用。新世界版本先比较非相机输入；仅相机位姿、投影或选择变化时校验相机并复用已提取的世界空间几何，非相机输入或源身份变化才重新提取。完整射线不变时也复用命中结果；每条新射线线性筛选材质可见性，再进行一次求交，透明层叠不会反复扫描整个数组。首次查询按需建立快照，结束拖动继续保留至世界替换或编辑器销毁；因此用额外 CPU 快照存储换取连续选择/导航后查询的复用，缓存不持有 World 所有权。

## 资源与保存

World 安装对象库时只追加一次不可变源几何和材质，放置实例共享源范围与资源句柄。每个实例有独立的名称、稳定 Object 身份、Transform 和组件；复制、替换材质、默认恢复和撤销均沿用现有编辑系统。修改同一个共享材质的参数会影响全部引用者。

创建对象进入当前活动的 Scene，因此保存世界后可重新打开。世界文档保留网格与材质定义，运行时预设索引不会成为保存对象的隐藏依赖。打开世界、切换场景和导入模型都会安装常用对象库。

当前最多同时启用 16 盏灯，超限时面板显示错误且不产生半创建实体。基本库仅含静态几何和单实体光源；不提供多实体组合预制体、模型缩略图、资产直接拖入、表面自动对齐或新的资源回收机制。

实现按职责拆分为 Gameplay 的 `WorldObjectPresets.cpp`、编辑器的 `EditorObjectPalette.cpp` 和视口事务；后端资源安装、纯 CPU 落点数学、真实 ImGui 行拖动与文档往返分别由自动测试覆盖，执行结果见 [验证记录](Validation.md)。
