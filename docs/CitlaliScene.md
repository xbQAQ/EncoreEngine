# 茜特拉莉展示场景

角色资源的原始说明禁止二次配布，原始模型、生成的 `citlali.pb` 与 `Content/Models/Citlali` 均不随 Git 仓库分发。本文记录本地资源的验证结果与生成方法；重现需要另行取得资源及相应使用授权。引擎默认场景与测试不依赖这些资源。

`citlali_scene_tool` 从用户提供的真实 FBX 导出文件生成可保存、重载和编辑的世界文档。工具调用正式 `ImportSceneFile`、`World::CreateScene`、`World::ExportDocument` 与 `SaveWorldDocument`，不维护另一份模型解析器。

## 重现

在项目根目录运行以下命令。输入目录需包含 `茜特菈琳.fbx`、`茜特拉莉_夏日.fbx`、`书.fbx`、`杯.fbx` 和 `武器.fbx`，并保留导出模型引用的原始贴图目录。

```powershell
& D:/CMake/bin/cmake.exe --build build --config Release --target citlali_scene_tool
& ./build/Workbench/citlali_scene_tool.exe `
    --source './茜特拉莉皮肤/Blender导出/FBX' `
    --output './Content/Worlds/citlali.pb'
```

可用 `--main-only` 只生成夏日主体，或以 `--height 1.65` 指定展示主体的身高。各模型按实际包围盒统一缩放，枢轴位于自身底部中心；展示位置与旋转保存在 ECS Transform，材质、法线、切线、UV 和表面范围保持对应。工具不会修改输入 FBX、Blend 或原始图像。

生成的角色展示包括夏日主体、茜特菈琳、书、杯与武器、开放地面、正面展示相机，以及主光、补光和轮廓面光源。它使用独立世界配置，不复用 Cornell 房间。每个 FBX 对应一个可整体选择、变换、复制和删除的模型对象，原始材质表面保存在对象内部，在详情中选择材质槽进行编辑，不再平铺为独立模型。

生成后，将完整 `Content` 目录同步到程序旁。在内容浏览器切换到“项目文件”，进入 `Worlds` 后双击 `citlali.pb`，或选中文件后点击“打开世界”。也可从世界面板打开该文件，或通过 `--scene D:/Render/Content/Worlds/citlali.pb` 启动。加载失败会保留当前世界并显示错误。

## 文件与像素

`Content/Worlds/citlali.pb` 保存官方 Protobuf 二进制作者配置与完整静态网格。纹理不以大量数字嵌入文本；`TextureAsset.rgba_path` 相对文档指向 `Content/Models/Citlali/image-<内容哈希>.rgba`。图像载荷是按行排列的小端 RGBA8，每个纹素四字节，保留原始解码分辨率与透明通道。工具不降采样，也不改变纹理色彩空间解释。

载入器先校验路径、尺寸、完整字节数与总容量，再恢复内存中的图像。缺失文件、截断或附加字节均使文档加载失败。内嵌 `rgba` 的旧文档继续可用。外置图像与作者数据在内存中仍完整存在；再次保存前逐像素核对载荷，另存到其他目录时自动重算相对路径。

单幅原始纹理上限为 256 MiB，整个世界图像上限为 1 GiB；模型、脚本和作者元数据的持久化文档仍限制为 64 MiB。必须一起移动 `Worlds` 和 `Models` 内容目录以保留相对关联。原 FBX 来源路径仅作元数据记录，加载展示世界无需重新打开 FBX。

## 导入范围

FBX 导入器使用固定版本 ufbx，烘焙文件的默认骨骼姿态与当前形态权重；展示场景是静态模型，不提供动画播放。Blender 自定义节点、MMD toon 或特效脚本不会自动变成引擎着色器，实际渲染使用导入的 PBR 常数与纹理及引擎 Disney 材质。

原始模型说明列出的提供者为 miHoYo，模型改造者为观海。生成文件属于本地用户资产的派生展示配置；使用与分发继续遵循输入目录的原始说明。
