# 接触边界漏光与 PBR 反射

本次修复保留 Cornell Box 原有 PBR 材质。高盒子的 Metallic 为 0.72、Roughness 为 0.2，前表面会映出白色地板，侧面会映出绿墙；这些反射在独立 Path Tracing 中也存在。低盒子另有 clearcoat。不能用压低 GI、关闭反射或增加环境遮蔽来判定接触漏光是否修复。

## 已确认的问题

第一处问题是重复的射线近裁剪。`RayOrigin` 已沿实际几何法线偏移起点，软件 BVH 和 DXR 又跳过起点后的 0.001 米。这样会忽略紧贴接收点的另一面，墙外光源仍能对室内接缝产生贡献。原回归中，背墙外点光的 raw HDR 均值为 0.000109743，最大值为 0.0192487。

第二处问题是接收点的浮点位置。光栅覆盖采用有限精度，透视插值的世界坐标可能略微越过源三角形。在右墙底边实际读回了 `(1.4, -3.06252e-7, 0.538685)`，该点落在地板下方，来自地板下点光的直接光为 2.06395。单纯缩小 `tMin` 无法纠正错误的接收点。射线使用 `origin + direction * t` 重建位置也可能发生邻面外的舍入。

## 实现

- 软件 AABB 从零开始裁剪，三角形接受 `t >= 0`，DXR 使用 `TMin = 0`。几何法线的起点偏移保留；没有增大偏移来掩盖错误。
- 公共 `TrianglePosition` 从非负、归一化的重心权重重建位置，并约束到源顶点各坐标分量的精确范围。光栅与射线求交共用此契约。
- GBuffer 传递透视正确的重心坐标，代替直接插值世界坐标。仅在覆盖样本的原始权重出现非正分量时，将权重下限设为 `1e-6`，选择同一三角形内极近的代表点，避免人工投影到相邻面上后依赖不稳定的零距离命中。当前 Cornell 尺度下这是微米量级的位置变化。
- 保留原始光栅覆盖，没有通过丢弃共享边片元制造孔洞。GBuffer 格式、材质/primitive 身份、法线与 UV 绑定保持兼容。

边界代表点是有限精度光栅覆盖的局部近似，不是任意网格、任意世界尺度下严格无偏的几何求解。当前 `RayOrigin` 仍使用固定法线偏移；极薄、很小或远离原点的场景需要另做误差界和尺度测试。

## 回归

独立运行接触边界测试：

```powershell
.\build\Release\renderer_integration_tests.exe --contact-only
```

测试保持原 Cornell 几何，使用纯不透明漫反射材质、无发光网格、无背景光，以便隔离几何遮挡；点光分别放到背墙外、地板下、右墙外。软件 BVH/DXR × PT/ReSTIR/SSGI × 三个位置共 18 组。使用 160x120、SPP=16、路径顶点数 5、每种状态 32 帧、射线阴影，直接读回曝光、Bloom 与 ACES 之前的 `Resolve.Spatial` 浮点资源。

每个像素要求非负且最大通道小于 `1e-8`，并检查 GBuffer 位置没有越过 Cornell 源几何范围。当前 18 组读回的最大值与均值均为零。相同光源移到房间内后，六个模式/后端的平均 raw HDR 红通道为约 1.70–2.72；移回背墙外的第一帧重新归零。这既覆盖稳定结果，也检查亮历史没有遗留。

正常 Cornell PBR 场景另用 16384 SPP 的 PT 参考和独立 PT 控制组检查 ReSTIR 的金属面误差；漫反射材质只作为测试对照，未替换实际场景材质。CTest 生成的对照图为：
