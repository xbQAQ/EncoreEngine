# 编辑器操作与撤销

当前编辑器提供单选透视视口、世界实体列表、对象详情、内容浏览器、性能时间线和编辑菜单。核心鼠标导航与变换快捷键参考 Epic 的 [Viewport Controls](https://dev.epicgames.com/documentation/unreal-engine/viewport-controls-in-unreal-engine?lang=en-US)，本页列出的是 EncoreEngine 当前实际实现的子集，不代表完整 Unreal Editor 功能。

## 窗口布局与性能

常用物体、渲染、世界、性能、视口、详情、场景资源、项目文件、材质脚本及 Gameplay 脚本均为独立停靠窗口。拖动页签可重排、合并或浮动；拖出主窗口后成为独立原生窗口，拖回停靠指示区即可重新停靠。停靠分隔线、浮动窗口边框可拖动调整尺寸，内容滚动区域随实际剩余空间伸展。世界实体列表和脚本输入区域还支持局部高度调整。

布局保存于 `%LOCALAPPDATA%/EncoreEngine/editor-layout-v3.ini`，旧版文件保留，可用编辑菜单中的布局重置操作恢复默认排列；离屏运行使用独立内存布局。项目文件列表使用内容窗口的剩余高度，不再预留固定行数把列表挤成一行。

项目文件支持右键“重命名”，也可在文件窗口选中条目后按 F2；文件和非空文件夹都在原目录内改名。对话框预填完整名称，允许修改扩展名和大小写，Enter 确认，Escape 或“取消”放弃。重名和无效名称会保留输入并显示错误，不覆盖已有目标；成功后刷新列表、选中新路径并重新读取文本预览。

单击 TXT、Markdown、JSON、HLSL、Lua 等文本可只读预览，支持选择复制和滚动。重命名仅修改磁盘条目名称，不改写已有世界文档、模型或脚本正文中的路径引用，也不自动重新导入或修改已载入的 World。

性能窗口默认不采集。点击开始录制后，按帧记录 CPU/GPU 的真实时间线；点击停止或达到 600 帧上限后关闭底层采集并保留结果，帧滑块可回看，清空可释放数据。缩放、横向滚动、搜索、事件选择及起止/耗时悬停均作用于所选帧。CPU 为图编译和命令录制时间，GPU 为原生 timestamp 间隔；两条轴各有时间原点，不能相加或据此推断并行重叠。GPU 结果在对应 fence 完成后才显示。覆盖范围与边界见 [`Profiling.md`](Profiling.md)。

## 选择与工具

点击视口中的可见表面选择一个实体；World 列表与视口共用选择。点击没有可接受表面的空白位置或在视口按 `Escape` 清空选择。Cornell 发光面和生成的矩形/圆盘发光面选择其 Light 所有者；点光、聚光与方向光可从 World 列表选择。

| 操作 | 行为 |
| --- | --- |
| `Q` | 选择工具，隐藏变换手柄。 |
| `W` | 移动工具。 |
| `E` | 旋转工具。 |
| `R` | 本地轴缩放工具；Light 不提供 Transform 缩放手柄。 |
| `Space` | 循环移动、旋转、缩放；选择工具进入移动，Light 跳过缩放。 |
| 拖动轴、平面或中心手柄 | 对所选实体执行当前变换。 |
| `Local` / `World` | 切换移动/旋转的坐标框架；缩放固定使用本地轴。 |
| `Snap` 或拖动时按住 `Ctrl` | 按工具栏中的增量进行位置、角度或比例吸附。 |
| 拖动时 `Escape` | 还原本次拖动开始时的 Transform，不生成撤销步骤。 |

工具快捷键要求视口具有焦点，且没有文字输入、相机导航或其他活动控件占用输入。右键飞行时的 `W/E/Q` 分别用于前进/上升/下降，不切换 Gizmo。视口工具栏提供相同工具的按钮及提示。

网格手柄围绕不可变源网格 AABB 的中心操作，带符号缩放与组合旋转跟随渲染器的变换约定。Light 的取景范围使用 Width、Height 或 Source radius 参数，区域灯的 Transform scale 不参与发光面生成。活动视角相机不显示视口变换手柄；相机参数仍可在检查器编辑。坐标和拾取契约见 [`EditorGizmo.md`](EditorGizmo.md)。

## 相机导航

在实际渲染图像内开始鼠标手势；工具栏、其他面板和图像黑边不启动导航。已捕获的手势可在移出图像后继续，松开所属鼠标键或失去编辑器/视口焦点后结束。Alt 导航优先于 Gizmo，即使光标位于变换手柄上也不会改变实体 Transform。

| 操作 | 行为 |
| --- | --- |
| `RMB` 拖动 | 旋转视角。 |
| `RMB + W/S` | 沿视线前进/后退。 |
| `RMB + A/D` | 沿相机左右轴移动。 |
| `RMB + Q/E` | 沿世界 -Y/+Y 下降/上升。 |
| `RMB + 滚轮` | 向上提高、向下降低持续飞行速度；此操作不推进相机。 |
| `MMB` 拖动，或 `RMB + LMB` 拖动 | 沿画面左右/上下平移相机及轨道焦点。 |
| `Alt + LMB` 拖动 | 围绕保留的焦点环绕。 |
| `Alt + MMB` 拖动 | 平移相机及焦点。 |
| `Alt + RMB` 拖动 | 朝焦点推进或后退。 |
| 非飞行状态滚轮 | 朝焦点推进或后退。 |
| `F` | 对所选可见网格或启用灯光取景，并更新轨道焦点。 |

左右两键平移时可先按住右键，再加入左键，避免左键先触发选择或 Gizmo。这里的上下轴使用工程的 Y-up 坐标，不采用 UE 的 Z-up 坐标。导航沿 `MakeCameraBasis` 的正 Z 前向相机基向量计算；相机 roll 保留，Q/E 始终按世界竖直方向移动。

F 使用源网格经过当前位置、旋转和带符号缩放后的边界，结合视口宽高比、垂直 FOV 及近裁剪面计算相机距离。灯光使用发光半径或区域发光面范围，不使用影响距离把整个照明区域装入视图。取景不改变当前相机朝向、roll、scale、FOV 或裁剪参数；特别大的对象仍可能需要调整 Far。无有效选择、隐藏网格或无效数据时不移动相机。首次取景前使用相机前方的默认焦点；F 更新焦点，平移则让相机和焦点一起移动。

飞行速度、俯仰角及推进距离均有限幅，非有限输入被拒绝。导航只编辑相机位姿，不通过改变 FOV 模拟推进。没有活动 Camera 时导航和 F 不执行，实体复制、删除和历史操作仍可使用。

## 实体编辑

常用物体栏支持将立方体、平面和五类光源拖入视口。拖动显示落点预览，松开后创建并选中，`Escape` 或在图像外释放取消；创建是一条独立撤销事务，放置数值成为对象默认值。模板、表面接受规则和回退平面详见 [`ObjectPlacement.md`](ObjectPlacement.md)。

详情窗口独立显示当前选择对象的名称、位置、旋转、缩放及可选组件。视口导航和选择先于详情更新，因此选择相机后可以在当前界面帧直接看到最新位姿数值。长中文参数名称在窄栏中会自动换行。

| 操作 | 行为 |
| --- | --- |
| `Ctrl+D` | 复制所选实体并选中新副本；初始 Transform 与原实体相同，可能完全重合。 |
| `Delete` | 删除所选实体并清空选择。 |
| World 的新建灯光操作 | 创建所选类型的 Light；最多同时启用 16 个灯光。 |
| 详情的“恢复对象默认值” | 恢复导入或首次创建时的作者组件，包括名称、位姿和原始材质分配；不改变实体身份。 |
| 材质的“恢复材质默认值” | 恢复当前材质资源的原始参数、表面脚本源码和源文件路径。 |
| 材质下拉 | 按资源名称及槽位选择现有材质。 |
| 拖放材质到详情材质控件 | 将资源分配给当前网格对象。 |
| 拖放材质到视口表面 | 按当前相机和可见性规则拾取落点，只修改命中对象的材质分配。 |

默认值基线不随后续编辑、撤销或模拟覆盖；对象恢复和材质恢复分别形成普通撤销事务。材质分配不会修改原始共享网格或其他对象的分配。光源拥有的发光几何保持受保护的材质绑定，防止光源采样与可见几何不一致。HLSL 与 Lua 源码编辑、运行及限制见 [`Scripting.md`](Scripting.md)。

Camera 实体不能删除或复制，包括未启用的 Camera。复制启用灯光也受 16 灯上限约束。网格副本共享 MeshResource 和材质资源，通过各自 Transform、可见性和材质槽形成独立实例；修改同一个材质资源的参数会影响所有引用它的实体。副本的渲染三角形和属性在提取时独立展开，拾取返回副本自身；实现与资源寿命见 [`Resources.md`](Resources.md)。

## 撤销与重做

| 操作 | 行为 |
| --- | --- |
| `Ctrl+Z` | 撤销上一次完成的作者操作。 |
| `Ctrl+Y` 或 `Ctrl+Shift+Z` | 重做。 |
| `Edit > Undo` / `Edit > Redo` | 执行同一历史操作，并显示可用操作的名称。 |
| Gizmo 拖动中 `Ctrl+Z` | 先取消本次拖动；本次按键不回放更早的操作。 |

历史最多保留 128 步。一次连续属性拖拽或一次 Gizmo 按下到松开的交互合并为一步；多个面板分别捕获编辑，只有同一面板的同一次活动控件交互可以合并。没有实际变化或最后完全抵消的编辑不留下空步骤。开始新的实际编辑会清除尚未重做的分支。Gizmo 失去视口焦点时结束交互并提交最后的有效位姿。

可撤销内容包括检查器组件/材质参数、持久渲染设置、Gizmo 变换、灯光创建及实体复制/删除。回放恢复实际编辑所关联的选择；单独选择实体或清空选择不会生成步骤。文字与数值输入激活期间保留 ImGui 原生局部撤销，编辑器快捷键不会同时撤销场景。

相机导航、F 取景、自动模拟、Play/Pause 和临时 GI reset 标记不进入作者操作历史。相机在检查器中的参数编辑属于普通属性事务。成功导入或替换场景时清空选择、捕获和历史；旧场景的撤销不能跨场景回放。历史保存稀疏变化值及非拥有资源句柄，不保存另一份完整世界或资产资源，也不新增资源回收政策。

## 当前边界

- 当前仅支持单选透视视口，没有多选、框选或正交视图。
- Snap 是数值增量吸附，没有顶点、表面或对象对齐吸附。
- 枢轴由源网格边界确定，不提供临时枢轴拖动或持久枢轴编辑。
- Alt+LMB 用于环绕，不支持 Alt 拖动 Gizmo 复制；复制使用 Ctrl+D。
- 未实现 UE 的全部鼠标模式、数字键盘/方向键替代映射、FOV 快捷键、Game/Immersive 模式或可配置快捷键系统。
- 共享网格实例在 CPU 提取阶段展开，GPU 几何容量按需增长；没有 GPU 硬件实例化、AS refit 或新的 GC 政策。

导航数学、历史与 Gizmo 有独立 CPU 测试；原生窗口交互测试覆盖生产 EditorUi 的输入与事务，Renderer 集成测试覆盖共享实例扩容及撤销/重做后的实际图像。实际构建、运行条件与结果见 [`Validation.md`](Validation.md)。
